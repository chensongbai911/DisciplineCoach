# Change: 添加自律教练小程序 V1.0 核心功能

## Why

创建一个专注于日常习惯养成与个人成长的微信小程序，帮助 20-40 岁用户在运动、饮食、睡眠、阅读、学习五个核心维度建立计划、坚持打卡，并通过数据反馈与拟人化小教练角色提供持续、友好、生动的监督和激励。通过会员制实现产品变现。

## What Changes

这是一个全新项目的初始版本(V1 MVP)，包含以下核心功能：

- **用户认证与账户管理**
  - 微信小程序登录 (wx.login + openid)
  - 用户信息管理 (昵称、头像、会员状态)
  - 首次引导流程

- **计划管理系统**
  - 五大维度计划配置：运动、饮食、睡眠、阅读、学习
  - 每个维度支持开启/关闭
  - 计划参数配置 (目标类型、数值、执行频率、提醒设置)
  - 会员可创建更多计划条目

- **打卡与记录系统**
  - 今日任务看板页面
  - 打卡交互流程 (数值输入、备注)
  - 补打卡机制 (过去7天)
  - 连续打卡天数统计

- **数据统计与可视化**
  - 周/月统计视图
  - 完成率、趋势图表 (柱状图/折线图)
  - 单维度与综合统计

- **会员付费系统**
  - 订阅制会员 (月/季/年)
  - 微信支付集成
  - 会员权益管理 (多计划、补签卡、高级统计)

- **激励与监督机制**
  - 拟人化小教练角色与动态文案
  - 等级经验值系统 (简化版)
  - 分享海报生成

- **系统设置与其他**
  - 个人中心页面
  - 通知与提醒设置 (订阅消息)
  - 意见反馈
  - 关于页面

## Impact

**新增能力 (Capabilities):**
- `user-auth` - 用户认证与账户管理
- `plan-management` - 计划管理系统
- `checkin-system` - 打卡与记录系统
- `statistics` - 数据统计与可视化
- `membership` - 会员付费系统
- `motivation` - 激励与监督机制
- `system-settings` - 系统设置与反馈

**技术栈:**
- 前端：微信小程序原生开发 (WXML + WXSS + JS)
- 后端：微信云开发 (CloudBase)
- 数据库：云数据库
- 支付：微信支付小程序API
- 图表：ECharts for Weixin

**数据模型:**
- User (用户表)
- Plan (计划表)
- Record (打卡记录表)
- Order (会员订单表)

**页面架构:**
- 底部导航: 今日、数据、我的 (3个tab)
- 主要页面: 首页、计划设置、打卡详情、数据统计、会员中心、个人中心、反馈、关于

**非功能需求:**
- 首页加载时间 ≤ 2秒
- 遵守微信平台隐私保护要求
- 适配主流微信版本与安卓/iOS机型
