# 图片资源放置说明

请将以下图片放置到本目录（miniprogram/assets/images/）：

必需（建议尺寸/格式）：
- coach-happy.png（教练头像/表情）128x128 PNG
- empty.png（通用空状态插图）240x240 PNG
- empty-task.png（任务配置空状态）240x240 PNG
- default-avatar.png（默认头像）128x128 PNG，圆形
- logo.png（应用 Logo）256x256 PNG，透明底

可选（用于分享）：
- share-cover.png（通用分享图 750x600 PNG）
- share-vip.png（会员页分享图 750x600 PNG）

可选（分类/维度图标，如需）：
- category-health.png / category-study.png / category-habit.png / category-work.png ... 96x96 PNG

命名规范：
- 全小写、连字符，扩展名 .png
- 避免中文文件名

注意：
- 当前代码已在缺图时使用表情符号进行兜底显示，不会报错。
- 一旦将对应文件放入本目录，页面将自动显示真实图片。
